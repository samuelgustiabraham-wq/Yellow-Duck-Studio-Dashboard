Kode Studio (Samakan di Laptop & iPhone)

Masukkan Kode Studio yang sama persis di laptop dan di iPhone (Safari / Home Screen) agar kedua perangkat terhubung ke ruang data yang sama.

Cara Pakai di Safari iPhone (Add to Home Screen)

  1. Buka link website dashboard ini di Safari iPhone, lalu masukkan Kode Studio di atas.
  2. Ketuk tombol Share (↑) di bar bawah Safari → pilih Add to Home Screen.
  3. Buka ikon Yellow Duck Studio dari Home Screen iPhone — setiap kali kamu tambah/edit project di laptop atau iPhone, datanya langsung tersinkron otomatis!

Install ke Desktop & iPhone Home Screen

Aplikasi Yellow Duck Studio tersinkron otomatis di cloud dan bisa dipasang sebagai aplikasi mandiri di laptop maupun iPhone.

1. Di Laptop (Chrome / Edge):

  1. Buka URL website dashboard ini di Chrome atau Edge.
  2. Klik menu titik tiga kanan atas → Cast, save, and share > Create shortcut... (atau Apps > Install this site as an app) dan centang "Open as window".

2. Di iPhone (Safari → Add to Home Screen):

  1. Buka URL website yang sama di Safari iPhone, ketuk ikon Share (↑) → Add to Home Screen.
  2. Pastikan Kode Studio di menu Sync Laptop & iPhone sama di kedua perangkat.
