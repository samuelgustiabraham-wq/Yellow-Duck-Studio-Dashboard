Cara Install ke Desktop Laptop

Aplikasi Yellow Duck Studio berjalan ringan dan menyimpan data lokal secara otomatis di laptopmu.

Langkah di Google Chrome / Microsoft Edge:

  1. Simpan kode HTML ini sebagai file YellowDuckStudio.html lalu buka di Chrome atau Edge.
  2. Klik menu titik tiga di pojok kanan atas browser → pilih Cast, save, and share > Create shortcut... (atau Apps > Install this site as an app di Edge).
  3. Centang "Open as window" lalu klik Create — ikon aplikasi langsung muncul di Desktop & Start Menu laptopmu!
